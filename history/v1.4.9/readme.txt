校园网共享助手 1.4.9
Wi-Fi 与有线接入统一版，带网络检测和独立清理工具。

首次使用
1. 连接校园 Wi-Fi 或网线，安装后打开助手。
2. 在“选择电脑如何接入校园网”中选择 Wi-Fi 或网线，点击“检测网络”。此操作只检查，不改账号、路由、热点或恢复备份。
   选择网线时，网线仍是上网来源；但 Windows 热点要靠 Wi-Fi 无线电向手机发射信号。因此不要关闭 Windows 的 Wi-Fi 开关，只需保持它不连接其他无线网络即可。
3. 根据检测提示处理网卡、地址或网关问题。显示“热点能力仍待实测”表示系统未能确认，不表示认证或手机已经联网。
4. 点击“填写校园账号”，选择实际校园连接，输入自己的账号密码并确认。
5. 先在官方天翼客户端断开并退出，再点击“启动共享”。等待认证和热点启动。
6. 点击“查看热点名称和密码”，让手机关闭移动数据、连接电脑热点，再打开新网页验证。

停止、托盘与账号
“停止并切回官方”会关闭能够确认属于本助手的共享，停止自身认证和自动任务，恢复记录的官方启动项、服务及本助手改动过的路由和优先级。
账号和首次恢复备份保留，下次可重新启动。停止后请在官方客户端登录；不再使用时可卸载。
收起到托盘会继续共享。退出时可以停止并退出、保持共享收起窗口或取消。停止失败会保留面板和重试提示。
“修改校园账号”只更新当前绑定连接的凭据。停止再启动后生效。

更换连接方式
Wi-Fi / 网线选项只改变本次界面选择。已经配置另一张网卡或网络时，不会直接改写首次恢复备份。
需要更换接入方式或网卡时，请先正常停止并使用清理工具恢复、卸载，再重新安装并选择新的连接。

网络稳定性与测速
1.4.3 起不再强制修改电脑全局网卡优先级，也不会删除 VPN、代理或其他网络工具已创建的认证专用路由。发现这类路由冲突时会停止启动并说明原因，避免以“能启动”为代价扰动原有网络。1.4.2 及更早版本已改过的网卡优先级，会在“停止并切回官方”时按首次备份恢复。
1.4.5 新增手动“网络测速”：仅在你点击后，最多约 25 秒、下载 8 MiB 加上传 2 MiB 地测量已绑定校园上游的下载/上传速度、网关延迟和丢包，同时读取热点状态与测速期间热点流量。测速不自动运行，不改网卡、路由、DNS、热点或认证；电脑测速正常不等于手机一定能上网。
1.4.6 将测速分开显示：左侧“电脑上游测速”检查电脑到校园网的下载、上传和延迟；右侧“手机 / 平板测速”只在点击并完成系统授权后临时开启一个热点私网内的本地页面。让每台已连热点的手机分别输入自己的名称并测试，即可分别显示该设备到电脑热点的下载/上传链路速度，不消耗校园网流量。该临时页面只允许热点子网的专用网络访问，十分钟自动结束；停止共享或卸载时也会自动撤销。

一键清理与卸载
点击面板“一键清理与卸载”。清理工具会在程序目录外运行，以便移除助手自身。面板会关闭，但打开清理工具和查看范围不会提前停止网络。
在清理工具中核对助手目录，查看识别依据、恢复要求及文件数量，再点击“确认清理并卸载”。确认后可能短暂断网。
工具使用自己携带的恢复组件，不依赖旧版卸载器。因此 unins000.exe 缺失或损坏时仍可处理有完整恢复资料的旧安装。
只有恢复成功才继续移除已识别的程序、任务、路由、快捷方式及本产品卸载记录。未知用户文件保留；本助手恢复备份缺失或归属无法确认时，保留现场并显示原因，请处理后重试。
清理不会按端口终止无关软件，不会重置所有网卡，不会删除学校官方客户端，也不处理原先独立配置的 CampusNetwork-Autostart 方案。
取消清理不改变配置或共享。若面板已关闭，可重新打开助手。

旧版打不开或无法安装新版
直接运行发布文件夹中的“校园网共享助手-清理与卸载.exe”。不必先找到或退出旧助手；工具会自动查找安装记录、助手任务、进程路径及快捷方式，并列出候选目录。核对选择后查看清理范围，确认后才关闭属于目标的旧面板并恢复清理。完成后运行新版安装包。
默认安装目录是系统 Program Files\GDPortalShare。工具会优先列出正式安装记录；有多个候选时请核对要处理的那一个。查找只是发现线索，后续仍会验证产品归属和恢复备份。
安装向导“安装、修复与旧版清理”页也有独立清理入口，不需要先打开旧助手。
清理不能重建已经被删除的原始恢复备份。遇到备份缺失，请保留剩余文件和提示交给维护人员，不要直接删除目录或清空全部任务。

安装与常规卸载
主程序位于系统 Program Files\GDPortalShare\校园网共享助手.exe。桌面和开始菜单均提供入口。
升级前完成或取消当前操作，停止共享并完全退出面板和托盘。覆盖修复保留账号和首次恢复备份。
“常规卸载”使用 Windows 卸载器；遇到旧卸载器损坏，改用独立清理工具。

适用条件与隐私
Windows 10 1809及以上或Windows 11，Intel/AMD 64位，支持 Windows 移动热点的无线网卡，以及兼容本组件的广东天翼校园认证。
Wi-Fi 接入与发射热点并用取决于网卡和驱动，必须以手机关闭移动数据后实际访问网页为准。
凭据按认证组件要求存放于本机受限安装目录。不要分享安装后的 Client、配置、日志、会话或恢复备份。
此版本没有可信数字签名，Windows 安全策略仍可能提示或阻止运行。不要为安装关闭系统防护。检查范围见发布目录“验证报告.md”。
认证组件：BadGhost520 / ESurfingClient-CVersion 2.2.0-r4，保持上游原版。许可证见 Client\portal\assets\LICENSE。
请在允许共享的网络上使用。
