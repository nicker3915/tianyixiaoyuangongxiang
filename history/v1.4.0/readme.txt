=========================================
 校园网共享助手 1.4.0（绿色免安装脚本版）
=========================================

【1.4.0 重大更新与核心特性】
1. 一键检索并清理旧版冲突与卡死程序（重点解决旧设备冲突）：
   - 如果电脑之前安装或运行过旧版本导致程序卡死、端口被占、无法配置：
     * 主面板新增【清理冲突与残留】专属按钮；
     * 文件夹内内置【清理冲突与类似程序.bat】；
     * 一键自动扫描并结束孤立残留进程、清理旧版后台计划任务、释放 8888 端口与路由锁定，环境彻底恢复干净！
2. 接入方式自由选择与技术路径彻底隔离（重点解决勾选与切换失败）：
   - 主界面【接入方式】单选按钮在任何时候均可勾选（即使未配置账号也可自由切换）：
     [ ● ] 网线连接 (以太网)    [ ○ ] 无线连接 (Wi-Fi)
   - 切换时实时显示该方式的硬件与连通检测状态；
   - 两条技术路径彻底隔离：
     * 【网线模式】：电脑通过网线以太网独立认证上网，完全解除对 Wi-Fi 名称的绑定要求；无线网卡专职负责向手机发射高速 Wi-Fi 热点；
     * 【无线模式】：电脑连接校园 Wi-Fi 信号，同时通过无线网卡并发热点；
     * 切换模式时自动清除旧网卡的 /32 路由与优先级，彻底杜绝路由冲突与锁死！
3. 彻底避免 Windows 拦截与误报：
   采用纯脚本免安装绿色模式，不依赖未签名的安装器，彻底避开 SmartScreen 拦截与 Defender 报毒，解压即可直接使用！
4. 内置网络与热点环境自检：
   双击【检查网络与热点环境.bat】即可一键检测网线连通性、无线网卡发射能力与系统移动热点支持。

-----------------------------------------
【使用指南】
1. 遇到卡死或旧版冲突时：
   - 优先双击【清理冲突与类似程序.bat】或在面板点击【清理冲突与残留】；
   - 脚本会自动清除旧版后台任务、解除端口占用并重置卡死的热点。

2. 启动助手：
   - 双击【双击打开助手.bat】打开面板。

3. 选择接入方式与配置账号：
   - 在面板中央直接选择【网线连接】或【无线连接】；
   - 点击【填写校园账号】（已选模式会自动带入），输入校园网账号密码保存；
   - 退出官方客户端，点击【启动共享】。
   - 提示管理员授权（UAC 弹窗）时请点击“是”。

4. 手机连接：
   - 点击界面的【查看热点名称和密码】；
   - 手机关闭蜂窝移动数据，连上电脑发射的热点，打开新网页测试。

5. 停止或切回官方：
   - 界面上点击【停止并切回官方】，或者双击运行【停止共享.bat】。

6. 卸载与清理：
   - 如不再使用，先运行【清理与恢复官方.bat】，自动注销任务并恢复官方启动项；
   - 恢复完成后，直接把整个文件夹删除即可。

-----------------------------------------
【文件清单说明】
- 双击打开助手.bat       : 启动主操作面板（推荐）
- 清理冲突与类似程序.bat : 强力检索并清理旧版残留进程、计划任务与路由锁
- 检查网络与热点环境.bat : 一键检测网线连通性与无线发射能力
- 停止共享.bat           : 快捷停止脚本
- 清理与恢复官方.bat     : 一键清理并恢复官方
- Clean-Conflicts.ps1    : 冲突检索与深度清理脚本
- Panel.ps1 / Manage.ps1 : 面板与核心控制脚本（开源透明）
- Client\                : 开源认证核心客户端（BadGhost520 ESurfingClient）
