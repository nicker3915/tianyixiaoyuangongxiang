# 维护源码

本目录用于另一台电脑上的 Codex 定位问题和重新打包。普通用户只需要上一级的 EXE 安装包；不要通过复制 stage 代替安装。

已按明确文件清单复制源码及干净 stage，并核对散列。未包含开发机的账号配置、原安装目录、日志、备份、网卡身份或会话。upstream.zip 是构建使用的公开客户端发行压缩包，并非要求用户使用的便携软件包。

## 结构

- payload：助手 PowerShell 和 C# 源码。
- stage：最终 EXE 对应的干净文件，按 payload.sha256 逐项校验。
- setup.iss、payload-files.iss：Inno Setup 安装规则和文件清单。
- build.py：从固定哈希的 upstream.zip 构建，不从已安装的 Client 目录取材。
- verify-binary.py：直接校验 EXE 内部所有文件与 payload.sha256，不执行安装。
- test-offline.ps1、test-network-selection.ps1、test-ui.ps1、test-entrypoints.ps1：离线测试。

## 构建

需要 Windows x64、Python 3、Windows PowerShell 5.1 / .NET Framework C# 编译器，以及 Inno Setup。原构建使用 Inno Setup 6.4.1。先检查本机现有工具，缺少时再说明需要的依赖，不假定原开发机路径有效。

build.py 先使用环境变量 ISCC 指定的编译器，再搜索 PATH，最后才尝试本机 Antigravity IDE 附带的编译器路径。可在当前进程设置 ISCC 为已核实的 ISCC.exe 完整路径，然后运行 python build.py。不要修改系统级环境变量或默默下载替代依赖。

源码修改后运行对应测试，并在构建后执行：

```
python verify-binary.py "dist\校园网共享助手-1.2.1-WiFi与有线版-x64.exe"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File test-offline.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File test-network-selection.ps1
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File test-ui.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File test-entrypoints.ps1
```

上述测试不等于实机联网验收。test-ui 会在离屏窗口中使用虚构凭据验证表单；test-entrypoints 会在 validation 子目录创建假的面板用于验证启动器及互斥，不执行校园认证。

如果更改版本或文件名，要同步 setup.iss、C# AssemblyVersion、readme.txt、产物说明和测试指向。分发时核对最终 EXE 的 SHA-256，并更新上一级 SHA256.txt。不要将安装后的 Client、settings.json、original-startup.json 或日志加入分发目录。
