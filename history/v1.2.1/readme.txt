校园网共享助手 1.2.1
广东天翼校园 Wi-Fi / 有线网转 Windows 移动热点

使用方法
1. 先连接校园 Wi-Fi 或插好网线，启用电脑的无线网卡。运行安装包，完成后会自动打开助手。
2. 点击「填写账号」，选择对应的「Wi-Fi」或「有线」连接，输入你自己的校园账号和密码，点击「确认」。可勾选「显示密码」核对输入。
3. 保存后手动重启电脑并登录 Windows，等待约 1–5 分钟。
4. 打开桌面的「校园网共享助手」，点击「查看热点名称和密码」。让手机连接热点，关闭手机移动数据，再打开一个新网页验证。

窗口中的功能
• 修改校园账号 — 保存新账号后重启生效。
• 启动 / 安全修复 — 请求认证及热点启动，后台复用已运行的认证进程。
• 暂停自动运行 — 暂停以后自动启动和守护。
• 恢复自动运行 — 启用自动启动并立即请求启动。
• 卸载并恢复官方软件 — 打开系统卸载确认。确认后停止本助手认证并恢复备份的官方开机项、服务启动方式和本助手调整的网络设置。可能短暂断网。卸载完成后手动重启，再用原来的官方客户端登录。

取消卸载会退出确认。恢复失败时，程序及备份会保留，请按提示解决问题后再次卸载。设置或修复进行时，先完成或取消当前操作，再卸载。
窗口显示最近一次启动流程的结果和时间。手机是否真正能上网，请以关闭移动数据后实际访问新网页为准。

适用条件
Windows 10 1809 及以上或 Windows 11，Intel / AMD 64 位电脑，支持 Windows「移动热点」的 Wi-Fi 网卡与驱动。
请使用日常使用的 Windows 管理员账户登录后设置，并在允许共享的网络上使用。
软件支持选择 Wi-Fi 和有线连接。校园 Wi-Fi 须兼容本组件使用的广东天翼认证方式。采用网页、802.1X 等其他认证方式的无线网络需另行适配。Wi-Fi 接入与热点并用取决于无线网卡及驱动支持，目标电脑还需实测。ARM 电脑未验证。
台式机有无线天线时请接好。网线、无线驱动和信号质量都会影响热点。

故障处理
• 无网卡可选 — 连接校园 Wi-Fi 或插好网线，等待分配 IPv4 地址后重新填写。
• 账号错误 — 点击「修改校园账号」，更正后重启。
• 电脑能上网、手机不能 — 在移动热点设置确认共享来源是设置时选择的校园连接，检查无线网卡与天线。
• 换网卡或换网段 — 卸载并恢复后，重新安装设置。
• 快捷方式失效或主程序缺失 — 关闭助手窗口，重新运行本版安装包。识别到正式安装记录后会修复程序文件和快捷方式，保留账号和原恢复备份。
• 本机是之前单独配置的旧版自动共享方案 — 本安装包会提示已有方案。请保留当前连接，由维护人员单独迁移。
• 原官方客户端需要继续保留在电脑上，恢复后仍使用自己的校园账号登录。

保存与回滚
首次设置会备份已识别的官方启动项，并把原为自动启动的官方服务改为手动。保存时不会主动停止当前认证，新的开机流程在重启后运行。
凭据按认证组件要求以明文保存在本机受限目录。管理接口仅监听本机且没有独立接口密码，本机程序仍可能访问凭据，请使用可信的个人电脑。
发给别人时只发送发布安装包。安装后的 Client 文件夹、日志和会话属于本人的私有数据。
程序文件安装到 C:\Program Files\GDPortalShare（系统盘不同则以安装向导显示为准）。
主程序名为「校园网共享助手.exe」，直接双击即可打开。开始菜单的「打开安装文件夹」、主窗口的「安装文件夹」都能定位本体。请保留主程序旁的脚本和 Client 文件夹。
