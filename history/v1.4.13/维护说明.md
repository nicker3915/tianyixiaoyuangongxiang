# 校园网共享助手 1.4.5

本工程保留 1.3.3 的安装完整性检查，并基于 1.4.0 的 Wi-Fi/有线界面完成前置检测与独立恢复清理。原始运行目录及账号未复制进工程或发布包。

## 1.4.5 补充

- 新增用户手动触发的上游测速和热点状态摘要；下载测试限制为 8 MiB、上传测试限制为 2 MiB，均强制绑定已选择的校园网卡。
- 测速模块不调用网卡、路由、DNS、热点、认证或任务的修改命令；测速失败不显示为 0 Mbps。

## 1.4.3 历史说明

- 有线模式明确说明 Wi-Fi 无线电只用于移动热点发射；关闭 Windows Wi-Fi 开关会关闭热点，但不会改变校园上游。
- 新配置保留系统自动网卡优先级，不再写入固定跃点；旧配置仍可在停止/卸载时恢复其历史改动。
- 认证专用路由改为先完整预检；发现非本助手路由冲突时拒绝启动，不删除对方路由。

## 1.4.2 历史说明

独立清理向导新增只读自动发现，无需知道安装位置或先退出旧程序。Cleanup.Discovery.ps1 收集精确产品登记、任务、进程、快捷方式及默认目录，候选仍由Preview复核。Cleanup.Processes.ps1 在确认后用实际路径、Windows参数解析和创建时间验证关闭目标面板，startup/watch包装进程仍交原恢复流程处理。取消、自动查找和Preview都不关闭进程或更改共享。

## 主要入口

- `payload/Panel.ps1`：先选接入方式，点击只读检测，再填写账号或启动。用户选择或检测不会直接重写配置和首次恢复备份。
- `payload/Network.ps1`：按接入类型、网卡 GUID、网络名称和 IPv4/网关识别候选。只读热点能力未知时提示待实测。
- `payload/Manage.ps1 -PreferredKind '有线'|'Wi-Fi'`：按类型过滤账号表单。更换绑定不覆盖首次备份，先正常恢复并清理后重新设置。
- `payload/Cleanup-Assistant.ps1` 与 `Cleanup.Core.ps1`：只读 Preview，或经确认执行 Remove。只使用清理工具携带的本版模块，不能调用旧目标的脚本或卸载器。
- `cleanup.iss`：独立清理向导。脚本从临时目录执行，移除目标时不依赖其卸载器。主面板和开始菜单会先将工具复制到目标之外，以便移除自身。
- `setup.iss`：安装向导内置旧版清理入口；未识别旧目录先恢复清理，已有正式安装可覆盖修复。全部安装组件经过 SHA-256 检查。

## 构建与测试

需要 Windows x64、Python 3、Windows PowerShell 5.1、系统 .NET Framework C# 编译器和 Inno Setup 6.4.1。普通使用者运行 EXE 不需要开发工具。

`build.py` 优先使用当前进程的 `ISCC` 环境变量指定 Inno 编译器，其次查 PATH，最后尝试原开发机的 Antigravity IDE 附带路径。换电脑时先核实工具位置，不修改系统安全设置。

```
python build.py
python verify-binary.py "dist\校园网共享助手-1.4.4-安装程序.exe"
python verify-binary.py "dist\校园网共享助手-清理与卸载.exe" cleanup-bundle.sha256
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File test-offline.ps1
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File test-network-selection.ps1
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File test-lifecycle.ps1
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File test-ui.ps1
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File test-panel.ps1
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File test-entrypoints.ps1
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File test-recovery-wait.ps1
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File test-cleanup.ps1
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File test-discovery.ps1
python test-installer.py
python test-cleaner-installer.py
```

测试使用隔离目录、虚构账号、模拟任务/注册/恢复，不执行真实校园认证或卸载。Inno 夹具隔离权限、安装注册和自动启动；独立工具夹具只处理未配置的假目录，恢复真实网络仍须在目标电脑授权实测。后台等待测试隔离 UAC 与 Shell 交互，避免把测试输出管道的寿命误当产品等待结果。

## 清理约束

清理目标必须经过产品归属及路径校验，拒绝磁盘、系统及个人主目录、官方天翼目录、原 `CampusNetwork-Autostart` 独立方案和链接目录。只清理精确匹配的本产品任务、进程、路由、快捷方式及卸载记录。

已配置目标必须有匹配的恢复备份。先恢复成功，再删除明确属于助手的文件。未知文件和空目录保留，并写入 `.gdportalshare-cleaned`，供安装器确认此目录已完成恢复。备份缺失、无法核实归属、仍有程序占用或恢复失败时，保留现场并说明原因；不能通过删除标记绕过恢复。

不得按端口结束无关进程、批量删除所有任务、重置全部物理网卡或默认修改官方服务。共享于其他安装的 LOCALAPPDATA 启动器日志不自动清空。不得在发布包中加入已安装的 Client、账号、会话、日志、网卡标识或恢复备份。
