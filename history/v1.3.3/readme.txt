校园网共享助手 1.3.3
校园 Wi-Fi / 有线网共享给手机，可随时停止并切回官方客户端。

首次使用
1. 连接校园 Wi-Fi 或网线，完成安装并打开助手。
2. 点击“填写校园账号”，选择实际校园连接，在本机输入账号密码并确认。
3. 先在官方天翼客户端断开并退出，再点击“启动共享”。允许 Windows 管理员授权，等待认证和热点完成。
4. 点击“查看热点名称和密码”。手机关闭移动数据，连接电脑热点，打开新网页验证。

随时停止
点击“停止并切回官方”。助手会暂停并禁用自己的自动任务，结束独立认证，关闭能够确认属于助手的热点，恢复其修改过的官方启动项、服务启动方式及网络路由、接口优先级。
账号、网络绑定和首次恢复备份会保留，之后点击“启动共享”可再次使用。停止后重启电脑也不会自行恢复助手共享。
官方客户端打开后，如未自动登录，请自己登录。再次启动助手前，请先断开并退出官方客户端，避免两个认证程序冲突。
停止遇到错误会保留备份和提示，不会把失败显示成成功；按提示处理后重试停止。来源不明或原本存在的热点不会被盲目关闭，可能需要在 Windows 热点设置中手动确认。

窗口与托盘
- “收起到托盘”：隐藏面板，继续保持当前共享；双击右下角助手图标可恢复面板。
- 托盘右键菜单：打开面板、启动共享、停止并切回官方、退出。
- 关闭窗口或点击“退出”：运行期间可选择“停止并退出”或“保持共享，收起窗口”；取消则不改变运行状态。
- 选择停止并退出时，只有停止成功后窗口才退出；失败会保留面板。

更改账号
点击“修改校园账号”保存正确内容。正在运行时，新内容暂存；先停止助手，再启动共享，使更正内容生效。无需卸载，也不要覆盖或删除 original-startup.json。
从 Wi-Fi 改为有线，或换网卡、校园 Wi-Fi 和网段时，需要先正常卸载并恢复，再重新安装、选择新连接。“修改校园账号”只修改已绑定连接的账号密码，不会更换网卡绑定。

状态说明
主界面显示绑定的校园连接、操作结果以及最近一次启动检查时间。显示启动完成不代替手机实际联网测试。启动失败时先检查是否仍打开官方客户端、校园 Wi-Fi 是否匹配、账号是否正确。
停止、重启、切换到其他网络后，必须根据当前状态重新确认连接，不要只看旧的成功时间。

安装与卸载
安装目录：系统 Program Files\GDPortalShare；主程序“校园网共享助手.exe”。桌面、开始菜单及“安装文件夹”按钮均可找到。
运行新版 EXE 可修复正式安装并保留账号与恢复备份。升级前完成或取消账号操作，点击“停止并切回官方”，再完全退出面板和托盘。安装器会检查助手窗口或设置操作是否仍打开，并核对全部安装组件；发现冲突会停下来提示，不会强制结束认证。
“卸载并恢复”会打开系统卸载确认；取消不应改变当前共享。确认卸载后执行恢复，再删除安装文件；恢复失败时保留程序和备份。
卸载后用官方客户端登录并实际打开网页验证。助手不会重新安装官方客户端，因此请保留原官方软件。
Windows 智能应用控制开启时可能拦截未签名程序。此安装包未提供可信数字签名；是否能安装取决于本机安全策略。

适用条件与数据
Windows 10 1809 及以上或 Windows 11，Intel/AMD 64位，支持移动热点的无线网卡。Wi-Fi接入和热点同时工作需实测。当前使用广东天翼认证组件，不代表兼容所有网页认证或802.1X校园网。
凭据按认证组件要求存放在本机受限安装目录；本机管理接口只监听本机。不要分享安装目录的Client、配置、日志、会话或恢复备份。发给别人只发送发布EXE。
请在允许共享的网络上使用。
